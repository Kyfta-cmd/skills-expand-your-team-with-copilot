# Mergington High School Activities

A super simple website application that allows students to view and sign up for extracurricular activities.

## Features

- View all available extracurricular activities
- Filter activities by difficulty level (Beginner, Intermediate, Advanced, or unassigned)
- Sign up for activities
- Share activity details with friends by using the Share, Copy Link, and Email buttons on each activity card
- Switch between light and dark mode using the header toggle

## Using the activity list

- Browse the activity cards to see descriptions, schedules, and open spots
- Use the sharing buttons on each card to send a direct link to that activity
- Open a shared activity link to jump straight to the highlighted activity card
- Switch between light and dark mode with the toggle in the header
